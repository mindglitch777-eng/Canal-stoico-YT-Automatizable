# Calm Fortune

Canal faceless de YouTube en inglés: estoicismo + dinero.

- `shorts/<id>/short.json` — guion de cada Short, por escenas
- `prompts/master-short.md` — formato del guion y reglas de retención
- `tools/` — voz (Edge TTS) y muestras de voces
- `remotion/` — plantillas de animación (1080x1920)
- `.github/workflows/` — prueba de plantillas, render de Shorts y muestras de voces en GitHub Actions
- `.claude/skills/` — skills de YouTube para Claude Code

El contexto completo del proyecto está en `CLAUDE.md`.
